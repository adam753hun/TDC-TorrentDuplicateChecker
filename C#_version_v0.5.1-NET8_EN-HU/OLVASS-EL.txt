WINDOWSOS KIADÁS
Csomagold ki a teljes mappát írható helyre. Indítsd a TDC.exe fájlt.
A többi fájlt és a licenceket is tartsd meg. Python nem kell.
Szükséges: telepített .NET 8 Desktop Runtime x64.
A sima .NET Runtime nem elég a Windows Forms felülethez.
Letöltés: https://dotnet.microsoft.com/download/dotnet/8.0
Windows / Desktop Runtime / x64 telepítőt válassz.
A Windows x64 rendszerhez készült; Windows 10-en ellenőriztük.

Nyilvántartás → Mappa hozzáadása: videók metaadatainak beolvasása.
Torrent ellenőrzése → .torrent ellenőrzése: v1 torrent összehasonlítása.
Dupla kattintás a találaton: részletes indok. A hasonló cím becslés.
Zöld: pontos név+méret. Sárga: hasonló cím. Piros: nincs találat.
A pontos név+méret sem bizonyít tartalmi azonosságot.

Az adatbázis és beállítások a TDC.exe melletti data mappában vannak.
Frissítéskor őrizd meg, továbbküldéskor a személyes data mappát hagyd ki.
A Python-verzió exportja importálható a Nyilvántartás fülön.
Import előtt a jelenlegi adatokról automatikus biztonsági mentés készül.

A Beállításokban válaszd ki a kliens .exe fájlját vagy parancsikonját,
és mentsd a beállításokat. Automatikus átadás és átadás utáni bezárás
külön kapcsolható. A kliens átadáskor letöltést is indíthat.
A fájltársítást a Windowsban te véglegesíted.

Ez a kisebb, telepített .NET 8-ra támaszkodó C#-os kiadás. A hasonlóság százaléka eltérhet a Python-verziótól.
ISO, játékok, magnet és v2/hibrid torrent még nem támogatott.
